## 1. Executive Summary

4×4 마방진(합 34, 1~16, 빈 칸 2개)을 다루는 학습자는 행·열 차이로 후보를 넣은 뒤 손으로 재계산·확인한다. **대각선을 포함한 전체 제약 판정이 늦게 드러나** 첫 칸부터 전체 재검산을 반복(최근 사례: 3회)해도 맞는 조합에 도달하지 못하고, 확인 비용만 쌓인 뒤 **미완료로 중단**한다.

본 프로젝트(세션 3)는 **자동 풀이·GUI가 아니라**, 행·열·대각·범위·중복 등 **제약 판정(Rule/Command)과 Test Loop**로 위 비용·재검산 루프를 코드·테스트로 재현·차단하는 것을 목표로 한다.

## 3. Persona (Mom Test)

**4×4 격자, 빈 칸 2개(0), 1~16, 합 34를 맞추는 학습자**

- 최근 시도: **손·종이만** (코드/에디터 미사용)
- 방법: 될 법한 숫자 → **차이 확인** → 후보 약 3개 → **3개 모두 시도**
- 동기: 과제 마감 없이 **심심해서** 시작한 경우 있음
- 실패 시: **다시 열지 않기로** 하는 경우 있음

---

## 4. Real Problem (One Sentence)

행·열 차이로 후보를 골라 칸에 넣고 손으로 다시 계산해 확인하는 과정에서, **대각선까지 포함한 판정이 늦게 드러나** 첫 칸부터 전부 다시 검산을 여러 번 반복해도 맞는 조합에 도달하지 못해, **확인 비용만 쌓인 뒤 미완료로 중단**한다.

*(솔루션名·미래 가정 없음 — Mom Test 준수)*

## 5. Surface Problems (Wrong Product Definitions)

아래는 **하지 않을** 잘못된 정의(표면 문제)이다.

- "4×4 마방진 **자동 풀이 프로그램**을 만든다."
- "빈 칸 2개에 **후보 숫자를 넣어 주는 Solver**를 만든다."
- "행·열·대각을 **한 번에 검증해 주는 Validator 앱**을 만든다."
- "손계산 **10분·5분을 줄여 주는 GUI**를 만든다."

## 6. Mom Test Evidence (Quoted)

1. "1일전이었고 될법한 숫자를 한번 넣어서 답과 얼마나 차이가 나는지 확인했어"
2. "대각선이 안 맞았을 때 … **첫번째부터 다시 확인 함** … **3번**" → "**안 맞아서 포기했어**" / "**그대로 두었어**" / "**다시 보지 않음**"
3. "**10분**" / "**5분** 다 확인 했어" / "**다 계산해야해서 시간이 오래 걸렸어**" / "**손으로 했어**"

**보완 질문 (미회수):** "5분 확인" 시 **10선(행4+열4+대각2) 전부** vs **대각만 나중** — 채점 시 −1, 추가 인터뷰 권장.
